# kc-ivy 1.0.27

Calibre 中整理 Kindle 收藏夹，预览后发送到 Kindle 执行，再读取结果并回填 Calibre 列。支持多归属、新建、改名、加入、移动、移除、删除收藏夹；这些操作保留书籍文件。

正式版 1.0.27，配套 KC 0.6.15；项目代码采用 MIT。正式支持基线为 Windows、Calibre 9.15 及以上、已越狱的 PW5 / 5.17.1.0.3 / USB 磁盘。MTP、迁移分享和其他机型保留实验或理论支持标识，详见[Kindle运行环境与理论支持范围](release/KINDLE_ENVIRONMENT.md)。

## 安装

1. Kindle 必须已经越狱，并具备能运行 documents 下 .sh 文件的脚本启动器。项目历史使用 KMC/KPM 的 KC 入口；该启动环境不由本包安装。原 Kindle Collections 不需要安装。没有可用启动器时先停止，不会自动执行 .sh。
2. Calibre → 首选项 → 插件 → 从文件加载插件，选择 kc-ivy_1.0.27.zip，重启 Calibre。
3. 连接 Kindle，等待识别。kc-ivy → 设备维护 → 安装/升级配套 KC；查看安装确认中的版本及传输方式。ZIP包含11个KC运行文件，不必手动复制JSON。只安装kc-ivy不更新设备端；本次新书直接整理需要升级设备端到KC0.6.15。
4. 安全弹出，在 Kindle 运行“KC刷新收藏夹”，重连后读取设备状态。
5. 首次编辑需准备能力测试，弹出后运行“KC验证编辑能力”，重连接收结果。失败先检查日志，不跳过验证。
6. 默认使用Calibre列与kc-ivy共同整理。在Calibre添加“逗号分隔、像标签一样”的多值文本列，查找名称和标题均可自定（例如 bookshelves / 我的书架），也可直接使用已有的多值文本列；重启后在同步设置选择它。审阅并导入Kindle现有归属。已有列值不要盲目覆盖；也可切换为纯kc-ivy手动整理。

## 日常流程

整理 → 修改预览 → 发送 → 安全弹出 → Kindle运行“KC执行收藏夹任务” → 重连读取结果。

发送成功不代表执行成功。草稿可撤销，已发送任务在任务记录核对；已确认结果才回填列。失败后先查看原任务并恢复剩余操作，不重复发送已完成部分。

加入保留其他归属；移动只退出指定原收藏夹；移除只退出该架；删除收藏夹保留书籍。未匹配 Calibre 的设备书可手动整理，也可在“同步设置 → 日常设置 → 设备书籍与书库记录”明确绑定已有记录或创建仅元数据记录，再使用同步列。详见 [设备独有书籍](release/DEVICE_BOOKS.md)。

## 新传入书籍

USB 磁盘模式及实验性 MTP 下，传书完成后点击“读取设备状态”，可发现 documents 下尚未进入快照的受支持文件，包括其他工具复制的书。可先整理，无需提前弹出刷新再重连；实际执行仍须安全弹出后运行 Kindle 任务，并通过原生索引和文件指纹核验。未索引 EPUB 不列入候选，不支持 KOReader 收藏。详见 [新书工作流](release/NEW_BOOKS.md)。

## 实验功能

1.0.27 补齐新书身份衔接、失效绑定修复、扫描取消与进度、分享导出范围确认；连接设备但未打开 kc-ivy 时不再弹出读取进度窗口。预览可查看设备副本路径并进入范围选择；提示详情区分文件发现与原生编号核验，任务入口保留待处理计数。详见 [使用边界与恢复](release/RELIABILITY.md)。

- **Kindle 屏幕进度**：KC 0.6.13 尝试通过系统 eips 显示居中大字卡片，包含中文阶段、操作序号和结果，三秒节流；不可用时继续执行并写日志。尚未真机验收，详见 [屏幕提示说明](release/SCREEN_PROGRESS.md)。

- **MTP** 默认关闭，只有连接到Calibre识别的MTP Kindle才可开启；没有KPW6实测。安装后使用带-MTP的刷新、验证、执行入口。可撤下核验一致的实验入口；原入口和任务数据保留。关闭开关不取消已发送任务。MTP暂不自动清理历史。
- **迁移与分享** 可选用，尚未完成两台真机迁移及大包验收。备份只含收藏关系；分享包含选中书籍文件及归属。默认导入独立书库，不自动覆盖同名书。
- macOS、Linux和其他Kindle型号允许探索，不属于当前已验证主范围。固件变化后重新验证编辑能力。

## 升级与回退

覆盖安装新kc-ivy并重启，不删除原设置。保留使用同一插件标识，草稿/任务/书库状态延续。普通USB升级KC先备份启动入口；“恢复设备启动入口”可恢复，1.0支持回退中断后继续并拒绝覆盖被用户改动的入口。MTP使用“撤下实验入口并关闭MTP”。入口回退不会撤销已经执行的收藏夹修改，也不将MTP设备转换成磁盘模式。

详见同目录 SUPPORT.md、KINDLE_ENVIRONMENT.md、CHANGELOG.md、BUILD.md、THIRD_PARTY.md。不要将个人诊断、书库或设备快照随源码公开。

## 设备版本管理

设备维护 → 设备版本管理：默认保留当前入口引用版本及最新两个其他版本。查看清单后点击清理，过期入口备份同步清理；不影响任务、书籍、收藏夹或数据库备份。此功能只支持 USB 磁盘连接，不自动清理，MTP 暂不支持。

## 原生字段与分享列映射

书架往返同步支持原生“标签”和多值文本自定义列。选择标签会使收藏整理结果回填标签；作者、丛书、出版方等通过分类规则读取，不回填来源。

分享包预览不创建列。导入独立新书库时创建默认“Kindle书架”列；导入当前库时将收藏关系合并到接收者选择的标签或自定义列。分享包保存来源列标识及收藏关系，不复制发送者的自定义列结构。Kindle 迁移使用收藏关系备份，不依赖原列名。

分享导入不会全库重命名标签或自定义分类；遇到仅大小写不同的同名分类，会在写入前停止并提示统一名称，或改用独立书库。

## 首次选择整理方式

默认联合整理。同步设置提供“专用书架列（推荐）”“使用原生标签”“仅在 kc-ivy 整理”三个选项。专用列可选择已有的多值文本自定义列，名称不限；没有时点“创建方法”。未选择列不能保存，插件不会替你自动选中第一列。原生标签无需新建列，但已确认的收藏整理结果也会回填标签。仅 kc-ivy 模式不需要列。已保存的选择再次打开时保留，主界面副标题旁显示当前方式。

新建专用列：kc-ivy → 同步设置 → 书架与同步设置 → 同步方式 → 新建书架列。填写标题与查找名称，创建后重启 Calibre，再选择该列并保存。类型自动设为多值文本，不会导入或覆盖已有归属。
