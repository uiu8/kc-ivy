# 设备独有书籍：KC++ 1.0.21

## 使用

- 只想整理 Kindle：读取设备状态，照常在 KC++ 加入、移动或移除书籍，不要求 Calibre 中有记录。
- 其他工具传书：文件放在 documents 内，传输完成后读取状态即可发现受支持候选。发送后仍需安全弹出，在 Kindle 执行；未索引或文件不符时不会猜测执行。MTP 需明确开启实验功能。
- 想使用 Calibre 列：在 Kindle 索引书籍并刷新收藏状态，重连读取；打开“同步设置 → 日常设置 → 设备书籍与书库记录”。左侧选择设备书，右侧搜索并选择对应记录，确认绑定。
- 书库没有记录：选择“创建仅元数据记录”，填写书名、作者。它没有电子书格式文件，不是备份，也不能当作可传输的电子书。
- 在同步设置选择标签或自定义多值文本列。范围为“全部已匹配书籍”时，下次预览自动包含绑定书；指定范围时需另行纳入。需要把设备现有归属放入列时使用“Kindle 收藏归属导入指定列”，先审阅预览。
- 解除只移除手动绑定，保留书库记录、列值、文件和原收藏关系；自动匹配不由此入口解除。

## 实现与边界

显式映射存放在当前 Calibre 书库的首选项中，键包含完整设备身份及真实 Kindle UUID，并校验原生记录的位置和内容标识。切换书库或设备不会共用映射；删除对应书库记录后不会把其数字编号误认成新书。新建记录、绑定不直接修改收藏夹或书架列；所有收藏变更仍经过预览与回执。

映射纳入元数据指纹，变更后旧预览失效。已有未完成任务或待回填记录时先处理任务再修改映射。书籍尚无真实编号时，只能先手动整理，不能建立持久书库绑定；索引刷新后再绑定。相同书名不自动匹配。设备快照带有另一个书库标记时，原有跨书库保护继续生效，需更新当前书库的设备状态后再进行列同步。

缺少 Calibre 设备书单时，已确认的显式映射仍可参与列同步；未验证的自动映射不会使用。原生系统不支持的文件不能靠扫描变成可操作书籍。Send to Kindle 转换后的书以设备原生记录为准。不支持 KOReader 收藏。

## 验证

使用临时真实 Calibre 数据库验证绑定持久化、解除、元数据记录创建、设备与书库隔离、列预览和回填；使用真实 Calibre MTP 缓存对象及模拟 I/O 验证独立文件发现和 v2 发送；Qt 离屏验证搜索与按钮操作。尚无本版真机验收，MTP 保持实验性。
