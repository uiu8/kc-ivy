# kc-ivy-kpw3 支持与故障处理

插件 1.0.1 / KC 0.7.0；目标 KPW3 5.16.2.1.1（4097470002），使用 USB 磁盘。安装与首次流程见 [使用说明](SOFTFLOAT.md)。

| 发生了什么 | 是否影响使用 | 下一步 |
| --- | --- | --- |
| .sh 打开为文本或没有运行入口 | Kindle 端任务尚未执行 | 使用已安装 KUAL 的 KC ivy KPW3 菜单；没有启动环境时先配置启动器，本包不安装它 |
| 环境报告 ENVIRONMENT_PASS 不为 1 | 停止初始化与普通任务 | 保留 kc-sync/logs 中最新环境报告，反馈型号和固件 |
| 电脑读取状态提示尚未初始化 | 尚无可用快照 | 安全弹出，在 Kindle 刷新收藏夹，完成后重连读取 |
| 环境检查通过，六步验证失败 | 尚不能确认编辑可用 | 读取原任务回执，保存日志，先核查未确认操作，勿重复创建测试 |
| 发送成功但没有确认回执 | 仅代表任务已传入 | 安全弹出后执行 Kindle 任务，重连读取结果 |
| 部分操作确认，其他待核验 | 已确认部分可能已生效 | 在原任务中核对与恢复剩余操作，不重新发送整批 |
| 新书待设备识别 | 文件被发现，未必已进入原生索引 | 执行时仍需核验索引及文件；若失败，在 Kindle 确认书能打开，再刷新、重连 |
| Calibre 显示 MTP | 本版不能用于此连接 | 核对型号，使用适合该设备的版本；本版不会自动改变连接模式 |

## 升级与回退

与主线共用插件标识及 kc-sync 数据目录，属于替换安装，不能同时安装两个版本。从主线或旧 KC 转入时安装 KC 0.7.0，并重新诊断、刷新、验证。已有相同 KC 0.7.0 且设备、固件、能力状态未变时，单独升级电脑插件无需重新安装设备端。

设备维护的“恢复设备启动入口”使用安装备份恢复四个脚本入口及 KUAL 文件。它不撤销已执行的收藏修改，不删除书籍、快照、任务或回执。入口被用户改动时会停止；中断后可重试同一备份。有待确认任务应先核验，勿删除 pending 或备份来绕过检查。

## 反馈

环境报告位于 Kindle 的 kc-sync/logs/KC环境检查-*.txt；执行日志也位于 kc-sync/logs。说明设备型号、完整固件号、Calibre/插件/KC 版本、使用 KUAL 还是脚本入口、失败步骤和任务号。环境报告按固定字段生成；其他执行日志发送前仍需检查个人书名和路径。不要提交 session_token、设备序列号、整库或完整设备备份。

完整自动化检查不替代 KPW3 真机验证；屏幕显示、跨两台真机迁移及大包分享仍需实际验收。
