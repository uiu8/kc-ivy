# 新书整理：kc-ivy-kpw3 1.0.2 / KC 0.7.0

先完成 [首次使用](SOFTFLOAT.md) 的环境检查、刷新与六步能力验证。

1. 通过 USB 磁盘向 Kindle 的 documents 传入受支持文件，等待传输完成。
2. 在插件点击“读取设备状态”。未进入快照的文件可能显示“待设备识别”，可先手动整理或由同步列生成归属；已有草稿保留。
3. 预览并发送，安全弹出，在 Kindle 运行“KC执行收藏夹任务”。
4. 重连读取回执。只回填已确认结果；未索引、文件改变或身份不唯一时，先处理原任务，再恢复剩余操作。

“读取设备状态”读取已有快照和文件信息，不会在 Kindle 重新生成原生索引。尚未出现在快照中的文件也不一定刚刚传入。在 Kindle 另行修改过收藏时，应先运行刷新入口再重连。

文件候选包括 AZW、AZW3、MOBI、PRC、KFX、PDF、TXT。未索引 EPUB 不作为可执行候选；官方转换书按实际设备记录处理。设备独有书不需要先加入 Calibre，列同步需要明确绑定或创建仅元数据记录。

执行时核验路径、大小、SHA-256 和真实 Kindle UUID；不按书名猜测、不修改书籍内容，也不强制修改系统索引。未索引项目报告冲突，已确认项目不会因重试重复执行。本版本不提供 MTP 流程。
