# 1.0.26 使用边界与恢复

## 新书与扫描

“已发现文件，索引未确认”仅说明存在文件。发送后进入“等待设备识别”；执行回执提供真实编号后显示“执行时已匹配编号”。没有匹配成功时，提示可能未索引、文件已变或不唯一，不把未知原因冒充确定的格式故障。未索引 EPUB 仍排除，已有原生记录按编号处理，不支持 KOReader。

读取时可查看目录扫描、候选文件核验进度并取消。MTP 底层文件传输的取消需等待驱动回调或返回；不会强制断开设备。扫描结束后的回执处理不提供中途取消，避免破坏既有事务。“扫描新增文件”默认打开；关闭可快速查看快照和回执，必须再打开并重新读取才能生成、发送修改。关闭扫描不代表设备没有新书。

临时编号只由设备、路径、内容指纹决定，Calibre 后来识别该文件不会改变它。旧编号经指纹验证后衔接。草稿保留待识别书籍的身份依据，索引后可以转为真实编号；文件变化则不猜测替换。已发送任务保持原文，通过回执或恢复流程处理。

## 失效绑定与多个副本

“设备书籍与书库记录”会列出原编号消失、路径或内容标识变化、书库记录删除、自动关联冲突。选择失效记录和左侧正确设备书后，可确认改绑；原记录被删除时需要解除旧绑定，再选择或创建记录。修复不搬移 Kindle 收藏，不改列值。

同一书库记录可以对应多个设备副本。预览显示每个副本的完整路径；选择“选择列同步副本”进入书籍范围，切换“只同步我选中的书籍”，用 Ctrl / Shift 选择需要的副本后保存。这个限制只约束列同步，手动加入/移动按其选书清单执行。后续新书若需自动纳入，可切回全部模式。

## 分享、书库与任务

分享导出先显示每本书的格式及处理方式。仅元数据记录不含电子书，格式缺失的记录也会跳过；没有任何可导出的书不能确认。导出前重新核对预览中的记录与格式，发现变化时重新预览。

提示详情显示当前书库 UUID 和快照中的书库来源。来源不一致时保持列同步保护，按提示刷新，不自动修改设备书库标记或清空列值。需要切回原书库或明确选择纯 kc-ivy 整理时由用户决定。

隐藏横幅不关闭任务。任务入口计数所有仍需核验或回填的记录，不只看最新一条；已关闭历史记录留在任务列表中。任务详情说明已确认成功项不会重复恢复，可关闭窗口稍后处理。恢复前仍逐项审阅，不重发不确定操作。

## 验收证据与尚缺设备

自动化范围：临时真实 Calibre 数据库、USB 文件夹模拟、Calibre MTP 文件缓存与模拟传输、1000 个候选文件、取消后数据不变、Qt 窗口、原生执行脚本模拟及发布包重建。它们不证明所有型号或真实断电条件下可用。

以下必须使用真实设备，当前尚未完成：

| 场景 | 操作与通过标准 | 状态 |
| --- | --- | --- |
| PW5 现有环境升级 | 草稿与列值保留；新书整理、回执、再次预览无重复变动 | 正式支持基线；用户仍应先用少量可恢复样本 |
| 真实 MTP / KPW6 | 大文件扫描进度、取消、发送；Kindle 执行后回执一致 | 缺真实 MTP 设备 |
| 两台 Kindle 迁移 | 原设备导出，在新设备核对书籍、导入关系；不同编号不串绑 | 缺第二台设备 |
| 可控拔线恢复 | 扫描或传输中拔线；重连不重做已确认项，不丢原列值 | 待专用小样本验收 |
| 重下载 / 重索引 | 原绑定明确标失效，人工改绑后下一次预览只影响目标书 | 待设备侧制造对应变化 |

对新增型号、固件和 MTP 设备，真机验收请先用少量可恢复样本，记录机型、固件、Calibre / kc-ivy / KC 版本、传输方式、操作步骤及回执。未取得结果前不宣称正式支持新增型号；这不影响已明确基线的正式发布。
