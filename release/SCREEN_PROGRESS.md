# Kindle 中文屏幕提示（实验）

kc-ivy 1.0.5 内含 KC 0.6.13。安装电脑插件并重启 Calibre，再从设备维护运行“安装 / 升级配套 KC”。安全弹出，在 Kindle 运行原来的 KC 入口。升级保留已发送任务；已有设备状态不需要为了升级先刷新。

三个入口统一使用居中的中文白底黑字卡片：

- 执行收藏夹任务：正在检查任务 → 正在备份与校验 → 正在执行 n/m → 正在刷新收藏夹 → 已完成：确认 n 项。
- 验证编辑能力：正在验证编辑能力 → 验证步骤 n/6 → 编辑能力验证通过（6/6）。仅本次六步全部通过才显示通过；否则显示尚未通过或执行中断。不能把只读状态核验当成编辑能力通过。
- 刷新收藏夹：正在准备刷新 → 正在刷新收藏夹 → 收藏夹状态已刷新。刷新只读取状态，不执行编辑任务。

有未确认项时显示“已确认 n 项，待核对 m 项”；中途异常显示“执行中断，请连接电脑查看”；任务之后快照失败则显示“刷新失败，请连接电脑查看”，不撤销已确认操作。n/m 是当前任务的步骤序号，并非成功数。详细信息仍以 kc-ivy 接收的回执为准。

字体只内嵌所需的 Noto Sans SC 字形，使用 SIL OFL 1.1，完整许可随包附带。不依赖 Kindle 自带字体，不在设备上加载整套字体。kc-screen 只查询屏幕尺寸并生成临时灰度 PNG，由系统 eips 更新局部屏幕；不停止系统服务、不清空整屏。临时图片位于 /tmp/kc-screen.*，正常结束清理，不进入书架。

通常三秒节流；快照阶段和最终结果强制更新。卡片不可用时回退原英文小字，显示命令失败或超时后停止本次提示，执行任务与日志继续。Kindle 界面自身可能覆盖卡片。关闭提示：在 kc-sync/state 创建空文件 screen-progress.off，删除该文件即可恢复。

日志增加 SCREEN_CALL_MS（单次绘图及 eips 调用耗时）、SCREEN_TOTAL_MS、SCREEN_CALLS；使用 /proc/uptime，10 ms 精度，统计同步调用耗时而非墨水屏物理稳定时间。ELAPSED_SECONDS 现在包含最终结果显示，比较旧日志时请注意口径变化。

原英文卡片已有用户真机可见反馈；中文卡片尚需真机验收。本机绘制、模拟执行测试不代替设备速度测量。

参考：https://github.com/google/fonts/tree/main/ofl/notosanssc 。未打包 FBInk 或其他第三方绘图程序。
