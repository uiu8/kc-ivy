# Kindle 屏幕提示

kc-ivy-kpw3 1.0.2 包含 KC 0.7.0 及 soft-float 屏幕辅助程序。环境诊断与编辑能力验证的顺序见 [使用说明](SOFTFLOAT.md)。

系统显示工具可用时，执行过程显示阶段、操作进度和结果；显示失败或超时会继续保留日志，不据此判定收藏操作失败。真实 KPW3 屏幕效果尚待验收。

只以设备回执和回读核验确认成功：发送完成、屏幕出现提示、读取到文件，均不能代替编辑确认。有待核对项目时重连查看原任务；刷新失败不撤销已确认的操作。

运行日志位于 kc-sync/logs。可通过设备上的 kc-sync/state/screen-progress.off 文件关闭屏幕提示；这不会删除任务或书籍。
