# kc-ivy-kpw3 运行环境

当前版本：插件 1.0.1，Kindle 配套 KC 0.7.0。

| 项目 | 要求与验证范围 |
| --- | --- |
| 目标设备 | KPW3 / Paperwhite 3，第七代，固件 5.16.2.1.1（4097470002） |
| 电脑 | Calibre 9.15 及以上；本地自动验证环境为 Windows |
| 连接 | USB 磁盘；本版本不提供 MTP 启用、安装或任务传输 |
| 启动环境 | 已越狱，且已有 .sh 启动器或 KUAL；本包不包含越狱及启动环境 |
| 运行文件 | KC 0.7.0，14 个文件；ARM soft-float 静态辅助程序 |
| SQLite | 优先使用满足要求的系统程序，否则使用内置 JSON1/readfile 备用程序 |
| 编辑 | 只读 cc.db，通过本地收藏服务提交；备份、回读及回执核验 |
| 真机状态 | 尚无本项目 KPW3 真机验证；首次必须完成环境检查和六步验证 |

公开资料支持旧固件 ARMv7 soft-float 的判断，见 [适配依据](SOFTFLOAT_RESEARCH.md)。主线 PW5 的实测不代表本版通过 KPW3 验证；自动化测试也不证明真实屏幕或本地收藏服务可用。

环境检查只读探测运行条件；六步验证会新建测试收藏夹、改名、加入与移除选定书籍、再次加入并删除测试收藏夹，不删除书籍文件。任一步失败先保存报告和任务，按 [故障处理](SUPPORT.md) 操作。

不支持未越狱 Kindle、Fire、手机应用或 KOReader 收藏体系。其他机型、固件及 macOS/Linux 尚未完成整条链验证。
