# kc-ivy 1.0.16 / KC 0.6.15：MTP 新书整理（实验）

尚无 KPW6 真机验证。不会自动启用 MTP；USB 磁盘连接保留原流程。

## 操作

启用实验性 MTP 后，安装/升级配套 KC 到 0.6.15（仅升级 PC 插件不够）。已有设备状态和有效编辑能力时，不必为升级重复刷新收藏夹。首次使用仍需完成初始化与能力验证。

1. 在 Calibre 将书传到 Kindle，等待传输任务结束。
2. 在 kc-ivy 读取设备状态；新书可以在书架中选择、加入或移动到收藏夹。
3. 生成修改预览并发送。这个阶段不需要先拔出再连接。
4. 断开连接，在 Kindle 运行“KC执行收藏夹任务-MTP”。
5. 重连后读取结果，确认归属并回填所选列。

## 实现与性能

从 Calibre MTP 驱动指定的 metadata.calibre / driveinfo.calibre 位置发现文件，以路径、大小及 SHA-256 描述新书。MTP 对象编号不当作 Kindle UUID。设备端执行时匹配 Kindle 索引，确认文件指纹后才修改收藏关系；未索引或内容变化会报告冲突。

只读取尚未出现在设备快照中的候选新书，不下载整库与数据库备份。新书通过临时磁盘文件分块计算指纹，不受协议 JSON 的 64 MiB 限制。同一连接、同一书单下复用指纹；发送前和恢复时重新读取校验。大书首次发现及发送会增加耗时，具体速度待真机测量。

MTP 交接仅对 edit 模式开放 request/v2，能力测试仍使用原协议。0.6.14 或更早 MTP 入口拒绝发送新书任务；原 USB 入口不改用 MTP。关闭实验功能保留书籍、收藏夹和任务，可通过实验设置撤下核验一致的 MTP 入口。关闭开关不会取消已发送任务。

## 验证边界

使用 Calibre 实际文件系统缓存、模拟 MTP I/O 和本地 shell/SQLite 执行链验证；不能替代 KPW6 的传输、索引与屏幕真机验收。
